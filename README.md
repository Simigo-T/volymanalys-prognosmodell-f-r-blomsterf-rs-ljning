# Blommor - Volymanalys

Volymanalys och prognosmodell för försäljning av snittblommor, buketter och krukväxter över flera butiker i Sverige.

## Innehåll (Volym_analys.xlsx)

- Försäljningsdata: Daglig transaktionsdata per butik och produkt (2023-2025): sålda enheter, pris, omsättning, kampanjer, lagerbrist, helgdagar
- Butiker: Butiksregister med region, kluster och storleksfaktor
- Produkter: Produktregister med bas-pris, hållbarhet, leverantör och buffertfaktor
- Volym för Region Stockholm: Veckovis volym per produkt, aggregerat för Stockholmsregionen
- Prognotisering modell: Prognosmodell per produkt med kampanj-, väder- och säsongsfaktorer
- Yearly increase / Increase factor / Specfik ökning: Årliga tillväxttrender, totalt och per produkt
- Approximation: Approximerad efterfrågan utifrån modellens faktorer
- Distribution and planering: Leverans- och lagerplanering per butik
- Helgdagskalender / Holidays: Svenska helgdagar 2023-2026 med förväntad påverkan på volym
- Leverans factor: Leveransfaktorer per leverantör/produkt
- Revenue lost: Beräknad förlorad omsättning (t.ex. vid lagerbrist)

## Nyckelresultat

- Total volym: 889 843 sålda enheter, 178,7 Mkr i omsättning (2023-2025)
- Tillväxt: ca +6% per år
- Kampanjeffekt: +132% i daglig volym
- Helgdagseffekt: +26% i daglig volym
- Lördag starkast, söndag svagast av veckodagarna
- Stockholm står för 34% av total volym, mer än dubbelt så mycket som Göteborg
- Volymledande produkter: Blandad vårbukett, Tulpaner, Röda rosor
- Lagerbristfrekvens: 2,1%
